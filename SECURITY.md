# Security Policy

Once this project has a public GitHub repository, report vulnerabilities
privately through that repository's GitHub Security Advisories feature. Do not
include secrets, personal data, or more reproduction detail than the report
requires.

No public repository or private vulnerability-intake channel is published yet.
Until one exists, do not disclose suspected vulnerabilities publicly. This
file intentionally lists no personal email address; publication of a private
intake channel will be a separate project decision.
