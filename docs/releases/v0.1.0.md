## English

Initial public source release of Remote DSH for macOS.

### Highlights

- Native AppKit/WebKit shell for a locally running DeepSeek Harness
- Automatic start-or-attach lifecycle for the configured SSH tunnel and Harness
- Native Finder directory picker for local coding projects
- Exact child-process ownership with Harness-then-SSH shutdown
- Numeric-loopback navigation and RPC boundaries
- Credential-free example configuration, diagnostic sanitization, and no
  wrapper telemetry
- Apple Silicon and macOS 14+ support

### Source-only release boundary

This release contains documentation and GitHub-generated source archives only.
It does not upload or distribute a prebuilt `.app`, DMG, Homebrew cask, updater,
Developer ID build, or notarized binary.

Users provide and manage their own SSH configuration, remote model service,
DeepSeek Harness installation and launcher, provider credentials, and optional
search tools. See the README for configuration, build, and verification steps.

## 简体中文

Remote DSH for macOS 的首个公开源码版本。

### 主要功能

- 使用原生 AppKit/WebKit 外壳呈现本地运行的 DeepSeek Harness
- 自动启动或连接配置的 SSH 隧道与 Harness
- 使用原生 Finder 目录选择器打开 Mac 本地代码项目
- 精确管理自身启动的子进程，并按先 Harness、后 SSH 的顺序退出
- 将导航与 RPC 限制在数字形式的本地回环地址
- 提供不含凭据的示例配置、诊断信息脱敏，并且本封装不发送遥测
- 支持 Apple Silicon 和 macOS 14+

### 仅提供源码的发布边界

本 Release 只包含说明文档和 GitHub 自动生成的源码归档，不上传或分发预构建
`.app`、DMG、Homebrew cask、自动更新器、Developer ID 构建或经过公证的二进制文件。

SSH 配置、远程模型服务、DeepSeek Harness 安装与启动器、模型服务商凭据和可选搜索
工具均由用户自行提供和管理。配置、构建与验证方法请参阅 README。
